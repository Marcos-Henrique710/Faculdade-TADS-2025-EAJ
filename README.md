Repositório criado para organizar e armazenar todas as atividades, listas resolvidas, slides e exemplos de código desenvolvidos durante o curso de **Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)** da **Escola Agrícola de Jundiaí (EAJ/UFRN)** no ano de 2025.  

Este repositório funciona como um **portfólio acadêmico**, documentando o aprendizado em cada disciplina e servindo como base de estudo para futuras revisões.  

---

## 📂 Estrutura do Repositório  

A organização das pastas segue a divisão natural das disciplinas e tipos de materiais:  

- 📝 **Atividades/**  
  Contém exercícios e trabalhos práticos desenvolvidos ao longo do semestre.  
  Exemplos: pequenos programas, respostas teóricas, relatórios.  

- 📑 **Listas/**  
  Armazena as listas de exercícios fornecidas pelos professores, sempre acompanhadas das resoluções.  
  Objetivo: servir como material de estudo e consulta para revisões e provas.  

- 🎞 **Slides/**  
  Pasta destinada a armazenar apresentações em PDF ou PowerPoint utilizadas em sala de aula.  
  Esses slides funcionam como material de apoio para revisão dos conceitos teóricos.  

- 💻 **Exemplos/**  
  Reúne códigos de exemplo apresentados durante as aulas ou feitos para praticar conceitos específicos.  
  Exemplos: programas em C/C++, scripts em Python, pequenos projetos em Java, etc.  

- 📦 **Outras pastas**  
  Dependendo da disciplina, podem existir diretórios específicos, como:  
  - `BancoDeDados/` → scripts SQL, modelos ER, dumps.  
  - `SistemasOperacionais/` → implementações e exercícios práticos.  
  - `Web/` → exercícios de HTML, CSS e JavaScript.  

---

## 🚀 Objetivo  

O propósito deste repositório é:  

- Centralizar **todo o material acadêmico** de 2025.  
- Servir como **repositório de aprendizado**, registrando a evolução do curso.  
- Facilitar o **estudo individual** e a preparação para provas.  
- Criar um **portfólio público** que poderá ser usado futuramente em entrevistas de estágio e emprego.  

---

## 🛠️ Tecnologias Utilizadas  

Ao longo das disciplinas, diferentes ferramentas, linguagens e ambientes são utilizados:  

- 🔹 **C / C++** → Introdução à programação, estruturas de dados.  
- ☕ **Java** → Programação orientada a objetos, projetos maiores.  
- 🐍 **Python** → Scripts, automação, introdução à ciência de dados.  
- 🌐 **HTML / CSS / JavaScript** → Desenvolvimento web básico.  
- 🗄 **PostgreSQL** → Modelagem e consultas em banco de dados.  
- ⚙️ **Sistemas Operacionais e Linux** → Comandos, scripts shell, gerenciamento de processos.  
- 🧰 **Ferramentas diversas** → Git/GitHub, VSCode, IntelliJ, pgAdmin, etc.
